# 마음 기록

매일의 감정을 간단히 기록하고, 지난 기록을 목록과 통계로 돌아보는 감정 일기장 웹앱입니다. HTML, CSS, 바닐라 JavaScript로 만들었으며 일기와 설정은 브라우저의 `localStorage`에 저장됩니다.

## 주요 기능

- 간단 모드 또는 일반 모드로 일기 작성
- 일기 목록·상세 조회, 수정, 삭제 및 감정별 필터
- 감정 비율 원형 그래프와 최근 4주 작성 일수 그래프
- 다크·라이트 모드, 작성 중 임시 저장

## 설치 및 실행

1. 저장소를 내려받거나 복제한 뒤 `diary` 폴더를 엽니다.
2. `index.html`을 브라우저에서 열어 사용합니다. 또는 VS Code의 Live Server 같은 정적 웹 서버로 `diary` 폴더를 실행하세요.

앱 사용에는 별도 패키지 설치나 백엔드가 필요하지 않습니다. 자동 테스트를 실행하려면 `diary` 폴더에서 다음 명령을 사용합니다.

```bash
npm install
npm test
```

## 사용 방법

1. 상단 메뉴의 **일기 쓰기**를 눌러 작성 화면을 엽니다.
2. **간단 모드**에서는 제목과 감정을 선택하고, **일반 모드**에서는 제목·내용·감정을 입력합니다.
3. 저장한 기록은 **일기 목록**에서 확인하고, 선택한 일기의 상세 화면에서 수정하거나 삭제합니다.
4. **통계**에서 감정 비율과 주별 기록 일수를 확인합니다. 화면의 테마 버튼으로 다크·라이트 모드를 전환할 수 있습니다.

> 기록과 설정은 현재 브라우저에 저장됩니다. 다른 브라우저나 기기와 자동으로 동기화되지 않습니다.
